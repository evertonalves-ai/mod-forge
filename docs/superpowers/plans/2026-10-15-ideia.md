# `ideia` mod Implementation Plan

> Executed inline in the session that wrote it (the user asked to continue without stopping). Compact form: each
> task lists files, interfaces and the tests that gate it; the code is written test-first during execution.

**Goal:** Example mod 13, `ideia`: two thinkers with different lines of thought and methods refine an idea by
dialogue, the user comments and steers, and the mod writes one Markdown document.

**Architecture:** Pure modules (pairs, flow, prompts, doc) hold every decision; `register.tsx` holds the hooks, the
pane and one detached runner that calls `$.model.complete`, appends events, rewrites `dialogue.jsonl` and updates
`$.state` atoms. Spec: `docs/superpowers/specs/2026-10-15-ideia-design.md`.

**Tech Stack:** Claude Code mods API (2.1.293 types), TSX, the `claude-code/testing` kit, `scripts/check-mod.mjs`.

## Global Constraints

- Folder `skills/claude-mod-forge/examples/ideia`, manifest in `_claude-plugin/` (renamed on copy).
- Command `/ideia`; pane id `ideia`; plugin name `ideia`.
- Thinkers: `$.model.complete` only, no tools; message cap 700 tokens, summary/suggestion 300 (`haiku`), document
  3000; `timeoutMs` 120000.
- Hotkeys are one lowercase letter or digit.
- Screen text through `hooks/i18n.ts` (`en` default, `pt-BR`); repository files in English.
- Writes only `dialogue.jsonl` and `ideia.md`, under `folder`, subfolder name from `[a-z0-9-]`.
- `check-mod.mjs` green: validate, strict tsc, kit tests.

### Task 1: Pure core (pairs, flow, prompts, doc)

**Files:** create `hooks/pairs.ts`, `hooks/flow.ts`, `hooks/prompts.ts`, `hooks/doc.ts`, `types/index.d.ts`;
test `tests/core.test.ts`.

**Interfaces (produced):**
- `pairs.ts`: `type Side = { lens: string; method: string }`, `type Pair = { id: string; a: Side; b: Side;
  bestFor: string }`, `pairsFor(lang): Pair[]`, `pairById(id, lang): Pair | undefined`,
  `parseCustomPair(text, lang): Pair | { error: string }`, `parseSuggestion(reply, lang): { pair: Pair; why: string }`.
- `flow.ts`: `type Event` (start | pair | msg | comment | summary | doc), `type Convo` (folded state),
  `fold(events): Convo`, `nextAction(convo, opts): Action` with `Action = speak(side, round, position) |
  summarize(round) | roundEnd | write | done`, `parseStatus(text): { text; isReady }`, `parseModFit(text):
  { text; isModFit }`, `slug(idea, date): string`, `clampRounds(n): number`, `parseEvents(jsonl): Event[]`,
  `toJsonl(events): string`.
- `prompts.ts`: `sideSystem(pair, side, lang)`, `messagePrompt(convo, side, round, position, maxRounds)`,
  `suggestPrompt(idea, lang)`, `summaryPrompt(convo, round, lang)`, `writerPrompt(convo, lang)`,
  `checkerPrompt(convo, doc, lang)`, `revisePrompt(convo, doc, notes, lang)`.
- `doc.ts`: `withFrontmatter(md, idea, date)`, `firstSentence(md)`.

**Tests:** fold of a full event list; `nextAction` walks A→B→A→summary→roundEnd per round, stops at `rounds`,
finishes early when both sides are ready from round 2; `slug` (accents, symbols, 40 chars); custom pair separators
and error; suggestion fallback on unknown id; STATUS / MOD parsing; prompts carry lens, method, comments, the
`<idea>` framing and the language line; frontmatter fields.
